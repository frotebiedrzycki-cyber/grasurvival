# BLACKWOOD: Lost Signal — projekt odzyskany

**Status:** pliki źródłowe zostały odzyskane z wcześniejszych paczek, ale kompilacja w Unreal Engine 5.8 i test gry nie zostały potwierdzone. To NIE JEST gotowy EXE.

Projekt C++ zawiera menu, sterowanie, HUD i ekwipunek pod TAB oraz pasek 1–0. Poprzednie wersje nie uruchamiały postaci poprawnie, więc nie należy uznawać naprawy za potwierdzoną bez testu na Windows.

Pełny ZIP z zasobami (188 MiB) został przygotowany w rozmowie ChatGPT pod nazwą `BLACKWOOD_v0.6_ODZYSKANY_PELNY_PROJEKT_UE58.zip`. Plik nie jest jeszcze przesłany do tego repozytorium. Zasoby zewnętrzne mogą podlegać ograniczeniom licencyjnym; publiczne udostępnienie wymaga sprawdzenia licencji.

Sposób uruchomienia odzyskanego projektu: rozpakuj ZIP, otwórz `BlackwoodSurvival.uproject` w Unreal Engine 5.8, pozwól przebudować moduły C++, użyj Play (nie Simulate). Pakowanie Windows można rozpocząć od `BUILD_WINDOWS.cmd` w głównym folderze projektu.

W repozytorium można przechowywać `Source`, `Config`, `.uproject` i dokumentację; duże zasoby Unreal należy w razie potrzeby trzymać poza zwykłym Git lub w Git LFS.
